# Code of Conduct

## Our Commitment

Kairo Shell aims to maintain a welcoming, productive, and respectful open-source community.

Everyone participating in the project is expected to treat others with respect regardless of experience level, background, identity, technical preferences, or familiarity with the project.

## Expected Behavior

Examples of positive behavior include:

- Giving constructive technical feedback
- Respecting different levels of experience
- Helping contributors understand project conventions
- Discussing disagreements based on technical merit
- Accepting reasonable criticism
- Keeping discussions relevant and productive
- Respecting contributors' time and effort

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or intimidation
- Discriminatory or hateful language
- Personal attacks
- Threats
- Deliberate disruption of project discussions
- Publishing another person's private information without permission
- Repeated hostile or insulting behavior
- Sexual harassment or unwanted sexual attention
- Spam or malicious contributions

Technical disagreement is normal. Personal attacks are not.

## Scope

This Code of Conduct applies to project spaces including:

- GitHub issues
- Pull requests
- Discussions
- Code review
- Project-related community spaces
- Other public communication representing Kairo Shell

## Enforcement

Project maintainers may edit, remove, reject, or lock content that violates these expectations.

Depending on severity and frequency, maintainers may issue a warning, temporarily restrict participation, or permanently ban someone from project spaces.

Serious threats, harassment, or illegal activity may be reported to the appropriate platform or authorities when necessary.

## Reporting

If you experience or witness behavior that violates this Code of Conduct, contact the project maintainer privately when possible rather than escalating the situation publicly.

Reports will be reviewed as fairly and confidentially as reasonably possible.

## Maintainer Responsibility

Maintainers are expected to apply these standards consistently and avoid using moderation tools to suppress legitimate technical disagreement or criticism.

The goal is a community where people can build, learn, disagree, and collaborate without hostility.
